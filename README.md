
# AstroVerse

Site interativo de exploração dos planetas e do Sistema Solar, desenvolvido como projeto acadêmico de Desenvolvimento Web.

## Objetivo
Proporcionar uma experiência interativa e educativa sobre o Sistema Solar, permitindo que os usuários conheçam os planetas, explorem constelações e testem seus conhecimentos sobre astronomia.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Three.js
- LocalStorage

## Funcionalidades
- Visualização interativa do Sistema Solar em 3D.
- Exploração dos oito planetas.
- Página informativa sobre constelações.
- Quiz de conhecimentos sobre astronomia.
- Sistema de cadastro e login.
- Perfil do usuário com histórico e pontuação.
- Armazenamento de dados utilizando LocalStorage.

## Como executar
1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta Astroverse-.
3. Execute o arquivo index.html em um navegador.

O projeto foi desenvolvido para funcionar localmente.
