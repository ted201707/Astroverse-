# AstroVerse

Uma experiência interativa e educativa para explorar o Sistema Solar, conhecer os planetas e descobrir o céu noturno.

## Sobre o projeto

O AstroVerse é um projeto acadêmico de desenvolvimento web. A proposta é apresentar conteúdos de astronomia em uma interface visual imersiva, responsiva e acessível, combinando páginas informativas com experiências interativas.

## Tecnologias

- HTML5 para estrutura e conteúdo.
- CSS3 para identidade visual, layouts responsivos e animações.
- JavaScript para interações, quiz, perfil e experiências dinâmicas.
- Three.js para a visualização tridimensional do Sistema Solar.
- LocalStorage para manter os dados locais de cadastro e resultados do quiz.

## Funcionalidades

- Sistema Solar 3D com Sol, oito planetas, órbitas, estrelas e efeitos espaciais.
- Seleção de planetas e acesso às páginas informativas.
- Exploração interativa dos planetas.
- Mapa ilustrativo de constelações com informações e curiosidades.
- Quiz de astronomia com pontuação, explicações e ranking local.
- Cadastro e login demonstrativos no próprio navegador.
- Perfil com estatísticas e histórico de quizzes.
- Conteúdos de vídeo e áudio.
- Layout adaptável para computadores, tablets e celulares.
- Preferência por movimento reduzido e estados de foco para navegação por teclado.

## Como executar

1. Faça o download ou clone este repositório.
2. Mantenha as pastas `Css`, `JavaScript`, `libs`, `img`, `audio` e `video` junto aos arquivos HTML.
3. Abra `index.html` em um navegador moderno.

Para uma experiência mais próxima da publicação, também é possível executar o projeto com a extensão Live Server do Visual Studio Code ou por um servidor HTTP local.

## Observações

- O cadastro e o login são demonstrações front-end. As informações ficam no LocalStorage do navegador e não substituem autenticação segura em servidor.
- Os dados do ranking são locais ao navegador utilizado.
- A representação de constelações é ilustrativa e não substitui cartas celestes científicas.
- Os recursos de vídeo e áudio dependem da presença dos arquivos correspondentes nas pastas do projeto.

## Acessibilidade e experiência

O projeto utiliza contraste reforçado, estados de foco visíveis, adaptação para telas menores e suporte à preferência do sistema por movimento reduzido.
